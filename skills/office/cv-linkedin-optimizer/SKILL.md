# 简历与领英优化器

## 适用场景
- 求职、内部转岗和人才包装

## 输入
- 当前简历
- 目标岗位 JD
- 真实经历
- 可量化成果

## 工作流程
1. 分析 JD 的核心能力要求。
2. 将经历映射到岗位要求。
3. 重写经历描述。
4. 加入真实量化结果。
5. 标出能力缺口和补救方式。

## 输出格式
- 职业简介
- 工作经历改写
- 技能关键词
- 领英标题
- 能力缺口

## Gotchas
- **经历真实性**：不编造经历。不得为用户虚构未任职的公司、未参与的项目或未获得的证书，即使这些能"完美匹配"JD。
- **成果量化**：不夸大成果。将"参与"改写成"主导"属于诚信风险。建议用户提供具体数据（如"日活从 10 万提升到 50 万"），模型仅负责润色表达。
- **去重检查**：不照抄 JD 原句。直接复制岗位要求会导致 ATS 系统标记为关键词堆砌，应做语义转换和同义替换。
