# 会议纪要组织器

## 适用场景
- 项目会、客户会、复盘会和管理例会

## 输入
- 会议记录或转录稿
- 可选：参会人、日期、项目名

## 工作流程
1. 区分事实、讨论、决策和行动项。
2. 提取已经明确的结论。
3. 标出行动项、负责人和截止时间。
4. 把未决事项放到开放问题。
5. 标出缺失信息。

## 输出格式
- 会议摘要
- 已做决策
- 行动项：负责人 / 动作 / 截止时间
- 开放问题
- 风险与依赖

## Gotchas
- **信息真实性**：不补造负责人和日期。若转录稿中未明确行动项 owner，标 `[待指定]`，禁止根据参会人列表猜测指派。
- **决策边界**：不把讨论意见写成已决策。需区分"会上有人提议"和"会议最终决议"，后者必须有主持人或决策者的明确确认语句。
- **缺失标注**：缺信息标 `[缺失]`。不要为了让纪要"看起来完整"而脑补背景上下文，不完整但准确的纪要优于完整但虚构的纪要。
