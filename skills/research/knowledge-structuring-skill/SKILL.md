# 知识结构化器

## 适用场景
- 知识库、项目资料和研究归档

## 输入
- 零散笔记、文章、会议材料或资料包
- 可选：目标分类方式

## 工作流程
1. 识别主题和实体。
2. 合并重复信息。
3. 建立层级结构。
4. 标出关系和依赖。
5. 生成可维护目录。

## 输出格式
- 总体框架
- 分类目录
- 核心概念
- 关系说明
- 待补资料

## Gotchas
- **事实优先**：不为了整齐而改写事实。不要为了分类体系的"美观"而扭曲原始材料的定义或关系，宁可在分类中保留一个"待归类"桶。
- **语义区分**：不合并语义不同的概念。模型容易将相近术语（如"微服务"和"分布式系统"）视为同义词，需根据上下文判断是否 truly equivalent。
- **来源保留**：保留来源线索。每个核心概念应附加其原始出处，方便用户回溯到原始材料做深度阅读，不要让结构化变成信息黑洞。
