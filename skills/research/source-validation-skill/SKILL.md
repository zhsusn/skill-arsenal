# 来源验证器

## 适用场景
- 研究、写作、投研、竞品分析和技术选型

## 输入
- 链接、文章、报告或引用
- 需要验证的问题

## 工作流程
1. 检查作者、机构和发布时间。
2. 判断是否一手来源。
3. 查找交叉验证材料。
4. 标出利益相关和可能偏见。
5. 给出可信度等级。

## 输出格式
- 来源列表
- 可信度评分
- 可确认事实
- 不确定信息
- 使用建议

## Gotchas
- **营销识别**：不把营销稿当事实。企业白皮书、PR 稿、赞助内容通常带有立场偏差，需标注"利益相关：内容由 XX 公司发布"。
- **时效性**：不把过期资料当当前事实。技术文档、市场数据需检查发布时间，超过 2 年的数据标 `[需确认时效性]`。
- **未验证标注**：无法确认时明确写"未验证"。禁止用"可能""或许"等模糊词降低可信度判断的明确性，必须给出五级评分（高/中高/中/中低/低）。
