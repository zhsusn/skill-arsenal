# 学术论文写作器

## 适用场景
- 正式研究写作

## 输入
- 主题
- 文章类型
- 目标字数
- 引用格式
- 已有资料

## 工作流程
1. 先明确研究问题。
2. 生成结构大纲。
3. 写引言、背景、方法、分析和结论。
4. 标出需要引用的位置。
5. 检查结论是否回应研究问题。

## 输出格式
- 标题建议
- 论文结构
- 各章节草稿
- 引用占位
- 待补资料清单

## Gotchas
- **来源真实性**：不编造来源。模型容易生成看似合理的引用格式（如 DOI、作者名），必须标记为 `[需要引用]`，禁止伪造。
- **研究边界**：不替用户伪造研究结果（如实验数据、p 值、样本量）。只负责结构组织和论证逻辑，数据部分留白。
- **引用占位**：需要引用的位置标 `[需要引用]`，不要为了段落完整性而编造参考文献列表。最终论文的引用必须由用户或文献检索工具补全。
