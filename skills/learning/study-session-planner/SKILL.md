# 学习时段规划器

## 适用场景
- 学生复习、员工培训和证书备考

## 输入
- 科目或主题
- 截止日期
- 每天可用时间
- 难度和优先级

## 工作流程
1. 按考试临近程度和难度排序。
2. 拆分每日学习块。
3. 安排新内容、复习和练习。
4. 加入间隔复习。
5. 保留休息和缓冲时间。

## 输出格式
- 总体计划
- 每日安排
- 学习块类型
- 复习点
- 风险提醒

## Gotchas
- **每日上限**：每天有效学习不超过 6 小时。超过此阈值后认知收益递减，计划应明确提示风险，而非继续填满日程。
- **主题轮换**：同一主题不连续安排过久。连续 3 小时以上同一科目会导致疲劳积累，建议穿插不同主题或安排主动回忆测试。
- **取舍提示**：时间不够时明确提示取舍。不要强行压缩休息时间，而应列出可延期或降低深度的主题，由用户决定优先级。
