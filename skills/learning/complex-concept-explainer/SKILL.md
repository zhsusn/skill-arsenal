# 复杂概念解释器

## 适用场景
- 技术概念、业务概念、金融概念或跨部门沟通

## 输入
- 一个复杂概念
- 目标读者
- 期望深度

## 工作流程
1. 先用一个直观类比建立直觉。
2. 用零术语版本解释。
3. 再给中级版本，引入必要术语。
4. 最后给技术版本。
5. 补充常见误解和相关概念。

## 输出格式
- 一句话解释
- 类比
- 基础版
- 中级版
- 技术版
- 常见误解
- 延伸概念

## Gotchas
- **类比边界**：类比不能误导。选择类比时需确保核心属性一致，并在文末明确标注"这个类比在什么情况下会失效"。
- **简化不失真**：简化不等于失真。删除细节时，不得改变概念的核心逻辑关系；若必须省略，应说明"此处省略了 XX 条件"。
- **不确定性标注**：不确定的地方要标注边界，写"在大多数场景下成立"或"目前学界对此仍有分歧"，避免给出绝对化结论。
