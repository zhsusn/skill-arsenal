# 记忆卡片生成器

## 适用场景
- 内部培训题库和间隔重复学习

## 输入
- 学习材料、笔记或文档
- 可选：主题标签、难度范围

## 工作流程
1. 提取事实、定义、流程、对比和例子。
2. 设计具体问题。
3. 给出 1-3 行简洁答案。
4. 按主题和难度打标签。
5. 从简单到困难排序。

## 输出格式
- 编号
- 正面问题
- 背面答案
- 标签
- 难度

## Gotchas
- **避免是非题**：不设计只能回答"是/否"的问题。这类问题无法触发主动回忆，应改为"什么是...""如何区分..."等开放式问法。
- **卡片独立性**：每张卡片独立可理解。避免卡片之间产生前置依赖（如卡片 B 需要记住卡片 A 的缩写），否则打乱复习顺序时会失效。
- **去重检查**：不重复同一个概念。同一术语的不同表述方式（如"TCP 三次握手"和"TCP connection establishment"）应合并为一张卡片，背面覆盖多种叫法。
