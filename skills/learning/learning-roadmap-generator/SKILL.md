# 学习路线图生成器

## 适用场景
- 学习新技术、新岗位能力或新业务领域

## 输入
- 想学习的主题
- 当前水平
- 每周可投入时间
- 目标完成时间

## 工作流程
1. 明确最终目标和当前起点。
2. 将目标拆成 4-12 周阶段。
3. 每周给出主题、目标、资源和练习。
4. 每周设置可验证检查点。
5. 标出前置依赖和风险。

## 输出格式
- 最终目标
- 当前水平假设
- 周计划表
- 每周练习
- 检查点

## Gotchas
- **时间上限**：不默认安排超过每周 5-7 小时。若用户表示"全力学习"，仍需先确认其可持续时间，避免计划过于激进导致放弃。
- **资源可及性**：推荐付费资源时给出免费替代。避免假设用户有特定平台订阅或预算，优先推荐公开课、官方文档和社区资源。
- **检查点可验证**：检查点写成"能完成什么"，不写"理解什么"。例如"能用 React 写一个 Todo List"优于"理解 React 状态管理"，后者难以客观验收。
