# 考试准备器

## 适用场景
- 复习、自测和培训考核

## 输入
- 学习材料、课程大纲或考试范围
- 可选：考试类型、题量、难度比例

## 工作流程
1. 识别最可能被考察的概念。
2. 按记忆、理解、应用、分析四类能力设计题目。
3. 生成选择题、简答题和案例题。
4. 给出答案和解释。
5. 标注每题难度。

## 输出格式
- 选择题 5-10 题
- 简答题 3-5 题
- 案例题 1-2 题
- 答案与解析

## Gotchas
- **材料边界**：所有题目必须基于用户提供的材料。模型容易将"相关领域常识"混入题目，导致超纲或偏离教学范围。
- **考点分散**：不在多题里重复考同一个点。生成后需做一轮去重检查，确保同一概念在不同题型中最多出现一次。
- **干扰项质量**：干扰项要真实，不写明显错误的选项。错误选项应反映常见误解或近似概念，而非荒谬答案，否则题目失去区分度。
