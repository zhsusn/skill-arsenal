# 结构化笔记生成器

## 适用场景
- 提炼概念、定义、例子、关系图和复习问题的学习场景

## 输入
- 主题、文章、PDF 内容、课堂笔记或视频转录稿
- 可选：学习目标、读者水平、考试范围

## 工作流程
1. 先识别材料的核心主题和层级。
2. 提取关键概念、定义、例子和公式。
3. 按'总览 -> 子主题 -> 关键点 -> 示例'组织。
4. 标出概念之间的关系。
5. 生成 3-5 个复习问题。

## 输出格式
- 主题标题
- 一页总览
- 分层笔记
- 概念关系
- 复习问题

## Gotchas
- **来源真实性**：不编造源材料中没有的信息。模型在整理跨学科内容时，容易用"常识"填补材料空白，必须逐句确认来自原文。
- **准确性优先**：不为了通俗牺牲准确性。遇到专业术语时，优先保留原文表述，可在括号内补充通俗解释，但不可替换核心概念。
- **缺失标注**：缺少上下文的地方标记为 `[需要补充]`，不要根据训练数据自行补全。若用户后续补充材料，应支持增量更新已有笔记。
