# 开场钩子生成器

## 适用场景
- 文章、视频、社交媒体或演示场景

## 输入
- 主题
- 目标读者
- 内容类型
- 核心观点

## 工作流程
1. 找到读者最关心的冲突或收益。
2. 生成多种开场路线。
3. 保持克制，不夸大。
4. 给出适用场景说明。

## 输出格式
- 判断型钩子
- 问题型钩子
- 场景型钩子
- 数据型钩子
- 最推荐版本

## Gotchas
- **拒绝标题党**：不写标题党。钩子必须能被正文支撑，若正文无法展开钩子的承诺，应降级推荐或明确提示"该钩子需要补充以下素材"。
- **焦虑控制**：不制造虚假焦虑。健康、财务、教育类内容尤其敏感，禁止使用"不这样做就完了"等灾难化叙事，除非有权威数据支撑。
- **正文支撑**：钩子要能被正文支撑。生成钩子后，模型应自检：如果用户只给钩子，正文还没写，需提示"请确认正文包含以下要点，否则建议换钩子"。
