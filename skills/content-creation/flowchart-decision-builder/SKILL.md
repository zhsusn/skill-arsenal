# 流程图与决策树构建器

## 适用场景
- 业务流程、系统流程和审批规则

## 输入
- 流程描述
- 决策条件
- 输出格式偏好

## 工作流程
1. 提取步骤。
2. 找出判断节点。
3. 标出输入、输出和异常路径。
4. 生成流程节点。
5. 检查是否有闭环或缺口。

## 输出格式
- 节点列表
- 条件分支
- Mermaid 流程图
- 异常路径

## Gotchas
- **节点简化**：保持节点简单。每个节点只描述一个动作或一个判断，禁止把"审批并归档"写成单一节点，应拆为"审批 → 归档"。
- **不增条件**：不自行添加未说明的决策条件。若用户只给了"如果预算充足则选 A"，不要脑补"如果团队大于 5 人也选 A"等额外分支。
- **分层处理**：复杂流程先分层。超过 15 个节点的流程应建议拆分为子流程图（Subgraph），并在主图中以"调用"方式引用，避免单图过于密集。
