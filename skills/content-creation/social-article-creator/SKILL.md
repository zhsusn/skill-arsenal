# Social Article Creator

多平台自媒体文章创作 Skill。将主题或素材转化为适配特定平台、能够打动读者的完整内容。

## 适用场景

- 用户给出一个主题，要求生成完整文章
- 用户要求将已有内容转换为知乎/头条/小红书/公众号风格
- 用户提到"去AI化""润色""让文章更自然"
- 用户需要标题方案或配图指导
- 用户要求"一稿多发"，同一内容适配多个平台

## 核心原则

1. **先思考再动笔**：创作前必须走完 11 维度内容构思框架（内部思考，不展示）。
2. **平台适配不是缩写**：不同平台不是同一篇文章的长短版本，而是完全不同的表达方式。
3. **去AI化是必选项**：不是删词，而是注入具体细节、真实矛盾和个性。
4. **金句自然嵌入**：从内容中生长出来，不是硬塞格言。
5. **互动不是乞讨**：好的互动让读者觉得自己有话要说。

## 创作流程

### 第一步：确认需求

向用户确认以下信息（如果用户已在 prompt 中说明，直接使用，不要重复提问）：

1. **主题/素材**：用户想写什么
2. **目标平台**：知乎 / 今日头条 / 小红书 / 微信公众号（可多选）
3. **文章立场**：客观中立 / 正面推荐 / 批评分析 / 对比分析
4. **目标受众**：专业人士 / 普通大众 / 年轻群体
5. **期望风格**：理性深度 / 情感共鸣 / 轻松幽默 / 犀利观点
6. **是否需要配图**：是 / 否
7. **预期长度**：短文(800字) / 中等(1500字) / 长文(2500字以上)

### 第二步：内容构思（内部）

在动笔之前，基于 `references/CONTENT_STRATEGY.md` 的 **11 个内容洞见维度**进行系统思考。这个思考过程是内在的——不需要把分析报告展示给用户，但必须真正完成。

关键产出：
- 一句话核心观点
- 2-3 个支撑副观点
- 主说服策略 + 辅助策略
- 情绪触发点设计
- 2-3 个金句（分布在开头、高潮、结尾）
- 情感曲线规划
- 互动钩子设计

### 第三步：按平台规范创作

根据用户选择的目标平台，读取 `references/PLATFORM_GUIDE.md` 的对应章节，按规范创作正文。

**知乎**：专业深度、逻辑清晰、数据驱动、建立作者权威性。引用需标明具体来源。
**今日头条**：信息密度高、段落极短、数字优先、前 3 段定生死。
**小红书**：口语化、闺蜜聊天感、短段落、Emoji 适度、清单结构、300-800 字。
**公众号**：节奏感、金句传播、开头 3 句定生死、1500-3000 字、结尾有力。

如果用户选择多平台，先创作一个"中间格式"通用草稿，再分别按各平台规范重写。严禁同一篇文章直接缩放字数。

### 第四步：生成标题方案

不论哪个平台，都提供 **5 个备选标题**，并标注策略：

```
1. [标题] — 策略：好奇心缺口
2. [标题] — 策略：数据冲击
3. [标题] — 策略：痛点共鸣
4. [标题] — 策略：反常识
5. [标题] — 策略：社交货币
```

用户可直接选用或要求调整。

### 第五步：去 AI 化润色

读取 `references/ANTI_AI_PATTERNS.md`，执行以下操作：

1. **识别**：扫描 20+ 种 AI 写作模式（过度强调意义、动词堆砌、高频连接词、模糊归因、三段式堆砌等）
2. **重写**：用自然表达替换 AI 腔，保持核心意思不变
3. **注入灵魂**：加入具体细节、真实矛盾、第一人称、节奏变化

修改后朗读检查：是否自然流畅？是否有"人味"？

### 第六步：配图指导

如用户需要，提供配图方案：

**封面图**
- 推荐构图方式和视觉风格
- 可直接使用的图片生成 prompt（中文即可）
- 推荐比例（知乎 1:1 或 16:9 / 头条 16:9 / 小红书 3:4 / 公众号 2.35:1）

**正文配图**
- 建议插图位置（在哪段之后）
- 每张配图的主题和作用（打破节奏、辅助说明、情绪强化）
- 每张图的生成 prompt

Prompt 原则：描述画面内容而非抽象概念；包含风格关键词；指定色调和情绪；指定构图。

## 输出格式

将最终内容整理为 Markdown 文件：

```markdown
# [最终选用的标题]

> 平台：[目标平台] | 字数：约[X]字 | 调性：[风格描述]

---

[正文内容]

---

## 备选标题

1. [标题1] — 策略：XXX
2. [标题2] — 策略：XXX
...

## 配图指导

### 封面图
- 推荐比例：[比例]
- 视觉风格：[描述]
- 生成 prompt：[prompt]

### 正文配图
#### 配图1（位置：第X段后）
- 作用：[打破节奏/辅助说明/情绪强化]
- 生成 prompt：[prompt]

## 话题标签

[平台相关标签，如适用]
```

文件名格式：`[主题简称]-[平台].md`

如为多平台输出，生成多个文件或在一个文件中用分隔线区分各平台版本。

## Gotchas

- **知乎要数据，小红书要情绪，头条要密度，公众号要节奏**。不同平台的差异是表达方式差异，不是字数差异。
- **禁止"同一篇文章改长短"**。把公众号文章直接删掉一半当小红书发，是严重违规。
- **去AI化不是同义词替换**。把"此外"改成"另外"没有任何意义，要重写整个句子结构和语气。
- **标题禁止纯标题党**。"震惊！99%的人不知道！"这类标题会降低账号长期价值。
- **小红书 Emoji 每段不超过 1 个**，禁止 `🔥🔥🔥` 或 `✅✅✅` 堆砌。
- **引用要具体**。不要"专家表示"，要写"张三在《财经》2025年3月刊中说"。
- **配图 prompt 要具体**。不要写"一张好看的图"，要写"一个年轻女性坐在咖啡店窗边，阳光透过玻璃洒在笔记本上，暖色调，手绘水彩风格，构图偏左留出右侧文字空间"。
- **一稿多发时，各平台版本必须独立重写**。只改标题和称呼是敷衍。
- **去AI化后保留适度不完美**。真人写作会有跑题、插入语、半成型的想法——这些是"人味"，不必全部修掉。
