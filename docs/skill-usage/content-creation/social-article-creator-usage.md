## 1. 快速开始

### 1.1 什么是 Social Article Creator？

`social-article-creator` 是一个多平台自媒体文章创作 Skill。它将主题或素材转化为适配特定平台、能够打动读者的完整内容，覆盖从选题构思到平台适配的全流程。

**核心能力**：
- 基于 11 维度内容构思框架进行系统性创作前思考
- 支持知乎、今日头条、小红书、微信公众号四平台差异化创作
- 内置去 AI 化润色能力，消除机器写作痕迹
- 自动生成 5 个备选标题及配图指导

**与通用写作的区别**：本 Skill 不是模板填空，而是让 AI 在创作前完成"像人一样思考"的过程，产出可直接发布的内容。

### 1.2 触发方式

| 方式 | 指令示例 |
|------|----------|
| 主题创作 | `帮我写一篇关于远程办公的知乎文章` |
| 指定平台 | `写个小红书笔记，主题是独居女生的周末仪式感` |
| 多平台适配 | `帮我写篇文章，同时发头条和公众号` |
| 内容润色 | `把这篇文章去AI化，改得更自然` |
| 标题生成 | `帮我想5个标题，主题是年轻人反消费主义` |
| 格式转换 | `把这篇知乎回答转成小红书风格` |

## 2. 使用步骤

### Step 1: 需求确认

触发后，Skill 会向你确认以下信息（如果你已在指令中说明，将跳过确认）：

| 确认项 | 说明 | 示例 |
|--------|------|------|
| 主题/素材 | 你想写什么 | "为什么年轻人开始反消费主义" |
| 目标平台 | 发布到哪里 | 知乎 / 头条 / 小红书 / 公众号（可多选） |
| 文章立场 | 你的态度 | 客观中立 / 正面推荐 / 批评分析 |
| 目标受众 | 写给谁看 | 专业人士 / 普通大众 / 年轻群体 |
| 期望风格 | 语气调性 | 理性深度 / 情感共鸣 / 轻松幽默 |
| 是否需要配图 | 视觉需求 | 是 / 否 |
| 预期长度 | 篇幅控制 | 短文(800字) / 中等(1500字) / 长文(2500字+) |

**减少确认的技巧**：在首次触发时尽可能说清楚，例如：
> "帮我写一篇理性深度的知乎文章，主题是 AI 写作工具评测，面向互联网从业者，1500字左右，需要配图。"

### Step 2: 内容构思（自动，内部执行）

Skill 自动基于 11 维度框架进行内部思考，你**不需要**做任何操作。这个步骤产出：
- 一句话核心观点
- 2-3 个支撑副观点
- 情绪触发点设计
- 2-3 个可传播金句
- 情感曲线规划
- 互动钩子设计

### Step 3: 平台创作

Skill 根据你选择的平台，自动应用对应规范创作正文。不同平台的差异不是字数差异，而是**表达方式差异**。

**关键区别**：
- 知乎：建立作者权威性，数据驱动，引用标明来源
- 头条：信息密度高，段落极短，数字优先
- 小红书：闺蜜聊天感，Emoji 适度，清单结构
- 公众号：节奏感+金句传播，开头3句定生死

### Step 4: 标题生成

Skill 为内容生成 5 个备选标题，并标注策略：

```
1. [标题] — 策略：好奇心缺口
2. [标题] — 策略：数据冲击
3. [标题] — 策略：痛点共鸣
4. [标题] — 策略：反常识
5. [标题] — 策略：社交货币
```

你可以直接选用，或要求调整某个标题。

### Step 5: 去 AI 化润色

Skill 自动执行以下检测和重写：
- 扫描 20+ 种 AI 写作模式（动词堆砌、高频连接词、模糊归因等）
- 用自然表达替换 AI 腔
- 注入具体细节、真实矛盾、第一人称和节奏变化

**自检标准**：朗读一遍，是否像真人写的？有没有"人味"？

### Step 6: 配图指导（如需要）

如你确认需要配图，Skill 提供：
- 封面图生成 prompt（含比例建议）
- 正文配图位置、作用和 prompt
- 各平台封面比例速查：知乎 1:1 或 16:9 / 头条 16:9 / 小红书 3:4 / 公众号 2.35:1

## 3. 平台差异化使用示例

### 3.1 知乎示例

**你的输入**：
> 帮我写一篇知乎文章，主题是"AI写作工具评测"，面向内容运营从业者，理性深度风格。

**Skill 执行要点**：
- 开头建立权威性："我在某互联网公司做内容运营，每天写3000字..."
- 数据驱动：引用具体渗透率、效率提升百分比
- 引用标明来源："根据艾瑞咨询《2025年中国AI应用市场报告》..."
- 结尾引导互动："以上是我的实际体验，欢迎同行交流~"

**预期输出风格**：
```markdown
# 作为每天要写3000字的内容从业者，我测了市面上主流的AI写作工具

先说背景：我在某互联网公司做内容运营...

本文主要讲3个维度：中文写作能力、上手难度、性价比。

---

## 一、Claude（强烈推荐）

先说结论：**目前中文写作体验最好的**。
...

**总结一下：**
1. Claude 适合长文写作
2. ...

以上是我的实际使用体验，欢迎同行交流~
```

### 3.2 今日头条示例

**你的输入**：
> 帮我写篇头条文章，主题是"实测8款AI写作工具"，信息密集风格。

**Skill 执行要点**：
- 标题带数字："实测8款AI写作工具后，我只留下了这3个"
- 段落极短：每段1-3句
- 前3段给价值：开头直接抛出结论
- 多用列表和加粗：方便快速扫描

**预期输出风格**：
```markdown
# 实测8款AI写作工具后，我只留下了这3个

去年我写了200篇文章，有一半用了AI工具。

测了8款，大部分不好用。
今天说3个真正帮我省时间的。

---

**第一个：Claude**

长文不会跑题。
改写一次过，不用反复调。

我用了三个月，效率提升大概40%。
...

你怎么看？你用过哪些AI写作工具？
```

### 3.3 小红书示例

**你的输入**：
> 帮我写个小红书笔记，主题是"独居女生的周末早餐仪式感"。

**Skill 执行要点**：
- 标题：Emoji 适度，制造好奇，"独居女生的早餐仪式感🥐 一个人也要好好吃"
- 开头快速共鸣："姐妹们！是不是周末经常睡到中午随便点外卖"
- 短段落+清单结构
- 结尾引导收藏和评论

**预期输出风格**：
```markdown
独居女生的早餐仪式感🥐 一个人也要好好吃

姐妹们！是不是周末经常睡到中午随便点外卖

亲测一个月，来分享给你 ⬇️

✓ 蛋白质：煎蛋/酸奶（2分钟）
✓ 水果：蓝莓/香蕉（1分钟）

总共不到10分钟，但仪式感拉满

📌 小tips：
• 提前一晚把餐具摆好
• 放一首喜欢的歌
• 不要边看手机边吃

有用记得收藏 📌
你的周末早餐吃什么？评论区聊聊~

#独居生活 #早餐仪式感 #自我提升 #生活方式
```

### 3.4 微信公众号示例

## 4. 一稿多发指南

当你需要将同一主题适配多个平台时：

### 推荐做法

直接告诉 Skill：
> "帮我基于这个主题，分别写知乎版和公众号版"

Skill 会：
1. 先完成一次 11 维度内容构思（共用）
2. 按知乎规范写一版
3. 按公众号规范独立重写一版（不是缩放字数）
4. 分别生成对应的标题和配图建议

### 禁止做法

❌ "先写个长文，然后帮我缩成小红书版本"
❌ "把这篇文章直接改成小红书格式"

**原因**：小红书不是公众号的缩短版。它们的表达方式、语气、结构完全不同。直接缩放会产生"穿着西装跳广场舞"的违和感。

### 多平台输出示例

**你的输入**：
> 主题是"为什么年轻人开始反消费主义"，帮我写知乎版和头条版。

**Skill 输出**：
- `反消费主义-zhihu.md`：专业深度，数据驱动，建立权威
- `反消费主义-toutiao.md`：信息密集，短段落，数字优先，前3段给价值

## 5. 输出解读

### 5.1 输出文件结构

单平台输出：
```
{主题简称}-{平台}.md
├── 正文内容
├── 备选标题（5个+策略）
├── 配图指导（封面+正文）
└── 话题标签（如适用）
```

多平台输出：
```
{主题简称}-zhihu.md
{主题简称}-toutiao.md
{主题简称}-xiaohongshu.md
...
```

### 5.2 正文质量自检清单

发布前，建议对照以下清单自检：

- [ ] **核心观点是否锐利**：读者能否用一句话复述你的观点？
- [ ] **开头是否抓人**：前3句/前3段是否让人想继续读？
- [ ] **平台适配是否准确**：语气、段落长度、结构是否符合目标平台？
- [ ] **是否有可传播的金句**：是否有2-3句能独立传播的话？
- [ ] **互动钩子是否自然**：结尾是否让读者有话想说？
- [ ] **去AI化是否到位**：读起来像真人写的，还是像机器生成的？
- [ ] **配图是否匹配**：封面和正文图是否能提升阅读体验？

## 6. 常见问题

### Q1：Skill 会自动联网搜索资料吗？

**不会主动搜索**。本 Skill 专注创作和润色，不内置搜索脚本。如果你需要基于最新数据写作，建议：
- 自行提供研究资料
- 在触发时附带资料链接或文档
- 与 `deep-research` 等研究类 Skill 组合使用

### Q2：去 AI 化会不会改变我的原意？

**不会**。去 AI 化的原则是：
- 保留核心观点和事实
- 改变的是表达方式（从" furthermore"到"还有一点"）
- 注入的是具体细节和真实感受

如果你发现原意被改变，可以直接指出并要求回退。

### Q3：同一主题在不同平台的标题可以一样吗？

**不建议**。Skill 会为每个平台独立生成标题：
- 知乎：问句/专业感，如"2026年了，AI写作工具到底发展到什么程度了？"
- 头条：数字/悬念，如"实测8款AI写作工具后，我只留下了这3个"
- 小红书：Emoji+短句，如"救命！这个AI帮我写东西效率翻倍 📝"
- 公众号：好奇/共鸣，如"不是买不起，是想明白了"

### Q4：去AI化后的文章还能被AI检测工具识别吗？

**大大降低识别率，但不能保证100%**。去AI化的目标是让文章读起来像真人写的，但不同检测工具的算法不同。如果追求极致自然，建议：
- 在 Skill 输出基础上加入更多个人经历
- 手动调整一些句式，加入你的口头禅
- 让文章带有一些"不完美"（跑题、插入语、半成型的想法）

### Q5：Skill 支持英文写作吗？

**当前版本以中文创作为主**。PLATFORM_GUIDE.md 的规范基于中文自媒体生态。英文写作需要调整语言风格参数和平台规范（英文平台如 Medium、LinkedIn 的规则不同）。

### Q6：我可以只使用其中某个步骤吗？

**可以**。Skill 支持灵活调整：
- 已有文章，只需要标题 → 说"帮我想5个标题"
- 已有文章，只需要去AI化 → 说"把这篇文章去AI化润色"
- 已有文章，只需要转平台 → 说"把这篇文章转成小红书风格"

### Q7：Skill 会生成配图吗？

**不会直接生成图片**。Skill 提供的是"配图指导"，包括：
- 图片生成 prompt（可喂给 Midjourney / Stable Diffusion / DALL-E 等）
- 构图建议和比例
- 配图位置规划

如果你需要直接生成图文卡片，建议与 `guizang-social-card` Skill 组合使用。

## 7. 红线与禁忌

| 红线 | 后果 | 正确处理 |
|------|------|----------|
| 把同一篇文章直接缩放字数当不同平台发 | 平台适配失败，阅读体验差 | 各平台独立重写 |
| 标题党（"震惊！""99%的人不知道！"） | 降低账号长期价值，平台可能降权 | 用好奇心缺口/数据冲击替代 |
| Emoji 堆砌（每句都加🔥✅💯） | 显得廉价，影响专业感 | 小红书每段0-1个，其他平台慎用 |
| "专家表示"等模糊归因 | 可信度下降，知乎用户反感 | 写明具体人名、机构、出处 |
| 忽略去AI化步骤 | 内容一眼假，互动率低 | 把去AI化当作必选项 |
| 配图 prompt 过于抽象 | 生成的图不贴合内容 | 描述画面内容+风格+色调+构图 |

## 8. 速查卡

```text
触发：自然语言，如"帮我写篇知乎文章，主题是..."
输入：主题/素材 + 目标平台 + 风格/长度要求（可选）
输出：结构化 Markdown（正文 + 备选标题 + 配图指导 + 标签）
原则：先思考再动笔、平台适配不是缩写、去AI化是必选项
流程：需求确认 → 11维构思 → 平台创作 → 标题生成 → 去AI化 → 配图指导
平台差异：知乎要数据、头条要密度、小红书要情绪、公众号要节奏
多平台：各版本必须独立重写，禁止直接缩放
去AI化：不是删词，是注入具体细节和真实矛盾
下一步：可配合 guizang-social-card 生成小红书图文/公众号封面
```
